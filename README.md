# FPA Landing Page

A responsive, original landing-page prototype for a fictional "Federal Personal Agency (FPA)".

## Files
- index.html — landing page
- styles.css — responsive styling
- script.js — mobile navigation and demo search
- FPA-Icon-RGB-R.jpg — supplied FPA logo

## Run
Open `index.html` in a browser.
